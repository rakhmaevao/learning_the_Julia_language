# 22. Generate Parentheses

**Сложность:** Medium  
**Темы:** String, Backtracking  
**LeetCode:** https://leetcode.com/problems/generate-parentheses/description/

---

Given `n` pairs of parentheses, write a function to _generate all combinations
of well-formed parentheses_.



**Example 1:**



    Input: n = 3
    Output: ["((()))","(()())","(())()","()(())","()()()"]


**Example 2:**



    Input: n = 1
    Output: ["()"]




**Constraints:**

  * `1 <= n <= 8`
